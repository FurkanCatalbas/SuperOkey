Poker card assets go here.

Current poker deck uses only values 1 through 8 for each color.

Compact naming:
- red1.png for ace
- red2.png through red8.png
- white1.png through white8.png
- black1.png through black8.png
- blue1.png through blue8.png

Long naming fallback:
- red_ace.png
- red_2.png through red_8.png
- white_ace.png through white_8.png
- black_ace.png through black_8.png
- blue_ace.png through blue_8.png

If a file is missing, the poker mode falls back to text cards.
